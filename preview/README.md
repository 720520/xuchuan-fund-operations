# 序川：基金运营工作台原型

这是用于视觉与交互评审的前端原型，不是正式业务系统。全部为虚构数据；没有真实邮箱、认证、租户安全、持久化、文件上传或附件解析。选择文件仅记录本地文件名，不读取或发送内容。

## 入口

- `/`：可点击工作台，通过侧栏切换页面。
- `/prototype/index.html`：8 个页面的 iframe 平铺总览。
- `/prototype/pages/*.html`：单页 HTML 预览包装；复用同一 React 界面，避免重复维护。

## 页面

工作概览、产品台账、产品详情、净值与估值、邮件归档、异常中心、上传与解析、组织与权限。

## 实现与限制

- 使用本地 proto-design 技能的 PRFAQ、设计规范和页面总览结构，并以 Sites / Vinext / React / Tailwind 承载。
- 预装 shadcn 提供按钮、输入、选择、开关、对话框和表格；Recharts 绘制演示曲线。
- 页面展示数值不用于实际投资、核算或报告；不承诺模拟数值之间满足业务勾稽。
- 管理员视图、其他牌照只读等仅为 UI 演示，不是真实授权。
- 交互状态仅在页面会话中保留，刷新重置；导航至概览可能重置业务页模拟状态。
- 还未确认的附件新产品建档规则不自动定案。
- 编译和 TypeScript 检查通过。预装组件及部分原型组合不满足脚手架全部严格 lint 规则，正式实现前应修整。
- 初始化依赖审计报告含高危项；未进行破坏性自动升级。正式开发前需审查适用性并升级验证，本预览不接触真实业务数据。

## 运行

`npm install` 后使用 `npm run dev`；`npm run build` 生成 Sites 构建。

## 评审后再开发

请先确认视觉、信息密度、导航、列表与详情布局。之后另行实现真实身份与牌照授权、邮箱适配、解析校验、不可删除归档、版本及审计、自动确认、异常流转与数据库。
