## 已交付行为

| 目标 | 当前行为与边界 |
|---|---|
| 减少逐笔核对缺件 | 启用后按交易日自动生成应收并检查；15:00 时不判迟到，超过后判迟到；后台每分钟节流检查，运行任务可能造成延迟 |
| 处理跨日仍未收到 | 按下一交易日及配置时间升级原待办，不每天重复创建；初始建议 09:00，管理员可调整 |
| 补发有记录且不误结案 | 记录实际账号、时间、说明，补发不等于收到，不自动关闭缺件 |
| 收到和确认分开 | 识别到净值或人工核对匹配原件后解除缺件；解析、校验和冲突单独保留；原件匹配要求原件访问权限 |
| 来源时间可追溯 | 邮件优先使用已保存的 IMAP INTERNALDATE（缺失时同步时间），上传/补录记录对应时间；迟到事实单独留痕 |
| 启停与历史有边界 | 首次启用不回溯之前缺件；主动暂停不补造暂停期应收，停机可从检查游标补查；清算、归档和停收取消对应应收并保留历史 |
| 保持现有能力 | 五家托管合成模板、净值自动确认/冲突/反账、多邮箱只读、权限、原件保护、迁移及启动器通过回归 |
| 邮件先分类再处理 | 只有净值/估值附件进入解析；明确待办进入邮件中心，普通邮件形成接收记录，未知用途进入待分类并保留原件 |
| 邮箱状态保持不变 | 同步代码只能使用只读目录、搜索和安全读取；没有删除、移动、复制、追加、标记或发送入口，附件解析只处理本地归档副本 |
| 首页查看交易安排 | 右栏紧凑月历显示交易日、法定节假日、调休及休市；每 30 天核验官方页面，内容变化提示复核；产品开放日不显示、不推测 |
| 集中整理产品资料 | 资料中心提供总览、整理视图和筛选；单份资料可保存标题、类别、业务日期/期间、说明及多个同牌照产品，修改检查版本并记录前后内容 |
| 分类决定解析 | 确认为净值与估值时进入或恢复净值解析；确认为其他类别时停止尚无业务结果的解析任务；既有净值结果不因分类调整而删除 |
