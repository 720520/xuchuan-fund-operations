# 托管解析适配器开发说明

## 当前适配范围

| 托管 | 发件域 | 适配器版本 | 已覆盖模板 |
|---|---|---|---|
| 中信证券 | `citics.com` | `custodian:citics:1` | 日间净值列表、运营数据订阅历史发送、ZIP 内 Excel |
| 华泰证券 | `htsc.com` | `custodian:htsc:1` | 基金净值表 |
| 光大证券 | `ebscn.com` | `custodian:ebscn:1` | 单日及区间资产净值表、总份额和 A/B 类份额 |
| 招商证券 | `cmschina.com.cn` | `custodian:cmschina:1` | 集合计划每日净值表、总份额和分级份额 |
| 申万宏源 | `swhysc.com` | `custodian:swhysc:1` | TA 净值表 |

所有适配器统一输出：`product_code`、`product_name`、`share_class`、`valuation_date`、`unit_nav`、`accumulated_nav`、`net_assets`、`total_shares` 和 `row_key`。数值精度、日期、必填字段及异常规则仍由公共解析层统一校验。

## 解析选择流程

1. 邮件附件优先使用原始邮件的发件域识别托管。
2. 在托管范围内使用工作表名称和固定表头签名确认模板，不能只凭文件名猜测。
3. 人工上传没有发件域时，依次使用各适配器的工作簿签名识别。
4. 已知托管的结构发生变化时，进入人工确认，不允许误套用其他托管的相似表头。
5. 未匹配专用适配器时，回退到严格的通用显式表头解析器。
6. ZIP 只读取受支持的 Excel/CSV 成员，并保留“压缩包成员名 + 工作表 + 行号”作为来源定位。

## 新增一个托管

在 `backend/app/custodian_parsers.py` 中新增 `CustodianAdapter` 子类：

```python
class NewCustodianAdapter(CustodianAdapter):
    name = "new_custodian"
    version = "1"
    domains = ("custodian.example.com",)

    def signature_matches(self, tables):
        # 使用固定工作表/表头组合，避免只匹配“单位净值”之类的通用字段。
        ...

    def parse(self, filename, tables, context):
        # 返回 AdapterResult(records=[...], errors=[...])。
        ...
```

然后将实例追加到 `ADAPTERS` 注册表。无需修改邮件同步、上传、解析任务或净值入库主流程。

## 版本与安全规则

- 托管修改模板后，应新增签名或提升适配器 `version`，不要静默改变旧模板含义。
- 产品主代码优先使用协会备案代码或总份额代码；分级代码应拆成产品主代码和 `share_class`。
- 不允许通过模糊名称自动关联产品。未知产品继续进入“待确认产品”，由运营确认后重新解析。
- 不允许静默舍入净值、规模或份额；无法确认的字段留空或生成解析异常。
- 新适配器必须增加合成样例测试，并用 `scripts/replay_custodian_parsers.py` 对历史归档做只读回放。

## 验证命令

```bash
PYTHONPATH=backend .venv/bin/pytest -q backend/tests/test_custodian_parsers.py
PYTHONPATH=backend .venv/bin/python scripts/replay_custodian_parsers.py
PYTHONPATH=backend .venv/bin/python scripts/requeue_custodian_documents.py
```

回放脚本只读取归档和数据库元数据，不写入净值、产品或解析任务。

批量重排队脚本默认也只预览。确认服务已经重启并加载最新适配器后，使用以下命令一次性处理，无需逐个点击：

```bash
PYTHONPATH=backend .venv/bin/python scripts/requeue_custodian_documents.py --apply
```
